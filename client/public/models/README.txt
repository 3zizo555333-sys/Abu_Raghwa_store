U²-NetP lightweight background-removal model

This model file is u2netp.onnx from the upstream rembg release:
https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx

The U-2-Net model is licensed under Apache License 2.0. The full license is in U-2-Net-LICENSE.txt.
Original project: https://github.com/xuebinqin/U-2-Net

The model is fetched by the browser only when an administrator starts background removal. Product images remain on the device during processing; only the final composed image is uploaded to the store's existing catalog-images bucket.
